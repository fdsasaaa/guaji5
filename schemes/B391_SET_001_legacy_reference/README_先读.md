# B391_SET_001 个位临号和值3码五期验证套 V1

## 核心规则

当最近两期的个位是临号时，取两期个位和值；和值大于9时取尾数，作为基数。然后用“基数-1、基数、基数+1”三个号码，做个位定位胆五期计划。

本版采用主定义：临号=数字差为1，例如 3-4、4-3、8-9、9-8。0-9 是否算环形临号单独作为观察口径，不并入主方案。

## 当前最新状态

历史文件最后两期个位为：6、4。

当前是否触发主方案：否。

所以当前不应立即启用投注，需继续等待下一次“最近两期个位相邻”的触发。

## 软件实现边界

这个方案需要判断“上两期个位是否为临号”，属于双期条件。当前工作包里没有已验证的自动双期触发模板。为了避免再次出现“用错误软件类别硬套”的问题，本套不交付伪自动TXT。

正确使用方式：人工或外部脚本发现触发后，再按《03_执行表》选择对应3码，执行5期计划；未触发时不投注。
