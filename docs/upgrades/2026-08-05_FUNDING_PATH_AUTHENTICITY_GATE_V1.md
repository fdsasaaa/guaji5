# 2026-08-05 资金路径真实性闸门 V1

## 根因

原功能编排校验只要求压力释放序列出现一次升档和一次降档，因此较短倍率模板整段重复后仍可通过。典型错误是把12档序列复制5次，包装成60档资金路径。该结构没有新增状态、事件或风险边界，本质仍是固定循环普通倍投。

## 修复

1. 新增 `tools/validate_funding_path_integrity.py`；
2. 新增对抗测试 `tools/test_funding_path_integrity.py`；
3. 新增 `11B_资金路径真实性与压力验证协议.md`；
4. CI执行资金真实性自检；
5. 功能编排中央配置登记资金证据文件、必需压力节点和10000条随机路径下限。

## 新闸门

- 识别完整序列是否由较短模板机械重复；
- 压力释放不得无限循环；
- 高级状态路径必须使用结构化 `from/on/to` 转移；
- 高级状态必须覆盖 `WIN`、`LOSS`、`CAP`；
- 必须说明部分回收规则；
- 必须计算连续挂10、20、30、40和50期；
- 随机压力模拟至少10000条路径；
- 历史数据不足1000期时只能标记快速实验，禁止长期安全或稳定盈利表述。

## 对抗用例

旧序列：

```text
1,1,2,2,3,3,5,5,3,2,1,1
```

复制5次后应同时触发：

```text
检测到12档模板机械重复
压力释放不得无限循环
```

## 边界

本升级阻止伪复杂资金路径通过静态验收，但不把尚未完成挂机软件真实运行验证的高级状态功能自动提升到E3。中央证据注册表仍是正式入选上限。
