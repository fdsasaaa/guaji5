## 正式闸门

PREFLIGHT 在进入 DIRECTOR 前必须生成 `data_source_snapshot.json`。适配器执行：

1. 下载固定 Release 地址；
2. 严格UTF-8和制表符解析；
3. 忽略 `#` 说明行和标题行；
4. 期号、5位号码、唯一性、升序、数量和时效校验；
5. 与上次成功最新期号比较；
6. 计算SHA-256；
7. 保存只读latest、有限快照和任务输入；
8. 失败时进入 `EXTERNAL_DATA_SOURCE_FAILED`，禁止正式生成。

## 缓存边界

缓存仅用于容灾、故障分析和证据追溯。正式调用始终先请求固定地址；不会因下载失败自动拿旧缓存伪装成最新数据。

## 安全边界

适配器只有HTTP读取能力，不包含向采集仓库提交、更新Release或删除数据的代码。私有仓库使用GitHub Secrets中的最小只读令牌。

## 测试

离线单元测试覆盖：

- 注释与标题忽略；
- 5位号码解析；
- 完全重复去重；
- 同期冲突拒绝；
- 非升序拒绝；
- 数据不足与过旧拒绝；
- 最新期号未推进拒绝；
- SHA-256、元数据、只读快照；
- 下载失败阻断；
- 私有Release只读API回退；
- `source`字段不进入分析；
- 非哈希流程不受影响。
