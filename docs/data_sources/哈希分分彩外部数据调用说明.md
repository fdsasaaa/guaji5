# 哈希分分彩外部历史数据调用说明

## 固定数据源

方案系统只读取以下固定地址：

```text
https://github.com/fdsasaaa/haxiffccaiji/releases/download/data-latest/hxffc_history.txt
```

不得改用提交 SHA、日期文件名、临时分支或网页当前显示的约200期数据。

## 正式调用流程

哈希分分彩任务必须在建立任务时明确声明 `hxffc`：

```bash
python tools/lottery_controller.py start \
  --request "生成哈希分分彩方案" \
  --data-source hxffc \
  --domain SCHEME \
  --run-id RUN-EXAMPLE \
  --run-root controller/runs
```

然后同步并冻结本次只读输入：

```bash
python tools/lottery_controller.py sync-data \
  --run-id RUN-EXAMPLE \
  --run-root controller/runs \
  --cache-root data_sources/hxffc
```

完成后推进状态：

```bash
python tools/lottery_controller.py advance \
  --run-id RUN-EXAMPLE \
  --to PREFLIGHT \
  --run-root controller/runs

python tools/lottery_controller.py advance \
  --run-id RUN-EXAMPLE \
  --to DIRECTOR \
  --run-root controller/runs
```

第二次推进前，总控会重新检查快照状态、固定地址、记录数、期号范围、SHA-256、标准分析输入和 `source` 字段隔离。任何一项失败都不能进入方案设计阶段。

成功时生成：

- `data_sources/hxffc/latest/hxffc_history.txt`
- `data_sources/hxffc/latest/metadata.json`
- `data_sources/hxffc/snapshots/<时间>_hxffc_history.txt`
- `controller/runs/<任务>/inputs/hxffc_history.txt`
- `controller/runs/<任务>/inputs/hxffc_metadata.json`
- `controller/runs/<任务>/inputs/hxffc_draws.json`
- `controller/runs/<任务>/data_source_snapshot.json`

这些目录属于运行时缓存和证据，不提交累计历史文件。方案生成器只读取本次任务的 `inputs/hxffc_draws.json`，不直接读取采集仓库，也不读取旧的固定200期文件。

## 独立诊断命令

`tools/sync_external_draws.py` 保留为数据源适配器的独立诊断入口，但正式方案应使用总控命令，以确保状态机不能绕过数据闸门。

## 私有仓库权限

采集仓库当前为私有时，在 `guaji5` 的 GitHub Secrets 中配置以下任一只读令牌：

- `HXFCCAIJI_READ_TOKEN`
- `HXFFC_DATA_TOKEN`

令牌只需读取 `fdsasaaa/haxiffccaiji` 的 Contents/Metadata 权限。不得赋予写入 Release、Actions 或仓库内容的权限，不得写入源码、日志、PPT或方案TXT。

适配器始终先访问固定 Release 地址。私有仓库导致固定地址返回401、403或404时，才使用同一个 `data-latest` 标签和同一个资产名，通过GitHub只读API回退下载；仍不依赖提交SHA或日期文件名。

## 强制停止条件

下载失败、空文件、字段错误、数据不足、过旧、非5位号码、期号冲突、非升序、最新期号未推进、快照或SHA-256失败时，总控以非零状态退出并写入BLOCKED证据。正式方案流程不得继续。

旧缓存不会在下载失败时自动接管正式生成，只用于故障分析和追溯。

## 非哈希分分彩

其他彩票流程不会自动调用该适配器。没有声明 `--data-source hxffc` 的任务只生成 `preflight.json` 的 `NOT_APPLICABLE` 记录，不要求哈希快照，也不会改变原有方案流程。
