# B405 历史验证与执行边界

B405 是在 B404 基础上的重构版。核心升级不是提高倍数，而是利用用户实际导出的高级倍投格式，把六路方案设计成可跳转、可重新监控、可软复位的状态网络。

## 已采用的新证据

- 高级倍投配置采用用户软件原生导出格式：GBK、无 BOM、CRLF。
- 每一局使用 16 字段，不再使用旧 9 字段。
- 中后监控 / 挂后监控可以为 True，对应 GUI 的重新监控。
- 中后跳转 / 挂后跳转可以为 True-主方案名，对应 GUI 的跳到其他方案。
- 高级倍投内部的中后ID / 挂后ID 与跨主方案跳转是两层独立动作。
- 高级倍投配置中的 SchemeCreator 采用软件原生导出边界，不再套用主方案空值规则。

## 设计边界

- B405 不声称单次命中必回本。
- B405 的目标是组合账户逐步清债：耐久组撑期数，回补组清中段债务，救援组做有限脉冲。
- 重新监控的精确时机、跳转后目标方案的高级倍投状态继承/重置，仍需要实际运行验证。
- 救援组失败后必须冷却或转回耐久组，不允许无限加倍。
