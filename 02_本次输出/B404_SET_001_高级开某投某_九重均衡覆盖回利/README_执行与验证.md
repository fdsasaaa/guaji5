# B404_SET_001 高级开某投某｜九重均衡覆盖回利

## 设计目标

本版替代 B403，避免“高级定码轮换内部局号 × 高级倍投ID”双状态机冲突。

- 一级分类：高级开某投某
- 玩法：定位胆 / 个位
- 11 个 TXT 同期参与，顶部“方案轮投”关闭
- 9 个八码轨 + 2 个九码轨
- 本金：5000 元
- 高级倍投：200 ID
- 最高倍数：3 倍
- 中后ID与挂后ID始终指向同一下一ID，使11个方案无论各自中/挂都同步推进
- ID200 的中后/挂后均回 ID1，避免忘记停机后长期停留高倍

## 九重均衡覆盖

对任意上一期个位触发值 t∈0..9：

- B404_01～B404_09 各排除一组相邻二码：`(t+i-1) mod 10, (t+i) mod 10`；
- B404_10 排除 `t`；
- B404_11 排除 `(t+9) mod 10`。

因此每个触发值下总排除次数为 20，0～9 每个数字恰好被排除 2 次，于是任意下一期个位结果都恰好被 11 个方案中的 9 个覆盖。

这不是预测优势，而是组合覆盖恒等式。

## 经济结构（沿用 B396 历史冻结参数，仅作门控）

- 单注金额假设：2 元
- 单注返奖假设：19.6 元
- 9 个八码轨成本：9×8×2=144 元
- 2 个九码轨成本：2×9×2=36 元
- 每期1倍总成本：180 元
- 任意结果固定 9 注中奖：9×19.6=176.4 元
- 返点 7% 时：12.6 元
- 1倍净结果：176.4+12.6-180=+9 元
- 盈亏平衡返点：2%
- 返点5%时：+5.4 元/1倍
- 返点2%时：0 元/1倍
- 0返点时：-3.6 元/1倍

因此本版的正净值完全依赖返奖与返点；返点≤2%时不得把本方案称为回利型。

## 200 ID 高级倍投

倍率不是追损型 1/2/4，而是低压波形：

- ID1-40：1倍
- ID41-80：`1,1,2,1,1,2,1,2` ×5
- ID81-120：`1,2,1,2,2,1,2,1` ×5
- ID121-160：`2,1,2,2,1,2,2,1` ×5
- ID161-190：`2,2,1,2,3,1` ×5
- ID191-200：`2,3` ×5

总倍率和=300，最高倍数=3。按180元/1倍计算，最大单期投注额=540元；200 ID 总流水=54,000元。若19.6返奖和7%返点均真实有效，则理论净结果=2,700元；5%返点时=1,620元；2%返点时=0元。

## 状态同步设计

每个高级倍投ID固定：

`中后ID=下一ID；挂后ID=下一ID`

因此11个方案即使同一期有9个中、2个挂，也不会像传统高级倍投那样产生不同的资金ID。各方案独立判断中/挂，但无论判断结果都进入同一下一ID，从结构上消除分叉。

## 执行前硬门槛

1. 必须确认当前平台单注2元返奖确为19.6元；否则全部重算。
2. 必须确认有效返点 >2%；≤2%禁止按回利方案执行。
3. 必须确认八码/九码、同一位置多方案并投仍正常计返点；若平台排除对冲/全覆盖投注返点，方案立即失效。
4. 必须先小额验证“高级开某投某”十个触发映射能按字段恢复。
5. 必须小额验证一个中方案和一个挂方案在同一期后都进入相同下一高级倍投ID。
6. 顶部“方案轮投”必须关闭。

## 证据边界

B396 Draft PR #30 提供了“高级开某投某”主TXT的历史可导入结构证据；当前 main 仍未把该独立一级分类升级为正式E3运行能力。因此本版可作为结构化交付/导入验证方案，实际运行行为在用户当前软件版本核对前不得虚升为E3。
