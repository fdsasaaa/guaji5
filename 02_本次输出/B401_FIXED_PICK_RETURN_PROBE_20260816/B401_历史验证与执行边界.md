# B401 固定取码回利型方案：验证边界与执行说明

## 结论

本批使用 `固定取码` 作为一级分类，投注承载采用定位胆单位置单码。按 2元/注、命中返奖19.6元、返点不计入证明、最低倍数0.001 计算，5000本金下严格逐档回利有效档位为 **111档**。

必须讲清楚：这不是200档强保本方案。若要求每条链首次命中都覆盖前亏、当期成本并留微利，200档在当前参数下数学上不可成立。

## 投注数字

- 万位：5
- 千位：5
- 百位：6
- 十位：7
- 个位：6
- 护栏并行：55676，低倍平衡，不纳入严格回利链

## 资金路径

单码定位胆每1倍成本2元，命中返奖19.6元，命中净收益17.6元。第n档倍数由：

`倍数 >= (此前累计亏损 + 目标微利) / 17.6`

向上按0.001倍取整。

第111档不中累计暴露：4522.716元；第112档会突破5000总本金边界。

## 执行纪律

1. 先模拟导入，确认固定取码字段被软件识别。
2. 只允许1-2条回利链真实跑；剩余方案最低倍监控。
3. 不允许把6条111档倍投链同时满额运行，否则总风险超过5000。
4. 如果平台最低投注单位不是0.001倍，本方案必须重新核算。
