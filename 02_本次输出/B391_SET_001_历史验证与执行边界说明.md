# 软件TXT实现边界说明

本方案没有交付可直接导入的软件TXT，不是遗漏，而是风控决定。

原因：

1. 方法需要同时判断上两期个位是否相邻；
2. 已验证的“高级开某投某”只能稳定表达上一期单个触发数字到下一期号码集合的映射；
3. 同一个上一期个位，可能来自两个不同临号组合，3码结果不同；
4. 强行用单期映射会把3码扩成5码，或者忽略临号条件，都会改变原始方案；
5. V3.9.0之后禁止用错误类别伪造可导入文件。

正确落地：

- 当前先作为人工触发/外部脚本触发方案；
- 等软件双期条件模板被验证后，再生成自动版TXT；
- 不得用10行常量映射或单期近似映射冒充正式自动方案。
