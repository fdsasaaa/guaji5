# B404 历史验证与执行边界

## 定位

B404不再追求“每一次单方案命中都立刻回本”，而是采用“组合债务接力回利”。

- 6个固定取码方案分成耐久组、回补组、救援组。
- 每个方案对应一份不同的高级倍投状态图。
- 中后不总是回到第一局，而是采用软复位：高压状态命中后降到中压区继续回收。
- 挂后也不无限加倍：救援组设置冷却段，失败后降压。

## 核算摘要

- 本金：5000元。
- 单倍成本：2元。
- 单倍返奖：19.6元。
- 总触发投注次数：367。
- 总命中次数：74。
- 历史窗口模拟总成本：2348.00元。
- 历史窗口模拟总返奖：5292.00元。
- 历史窗口组合累计盈亏：2944.00元。
- 按历史触发节奏全挂压力成本：3574.00元。

## 边界

1. B404不是“每档单中必回利”模型。
2. B404的回利判断对象是组合账户，不是单个方案。
3. 高级倍投不会提高号码命中概率，只改变资金压力的分布方式。
4. 真实运行中若命中频率明显低于历史窗口，必须停止或降压。
