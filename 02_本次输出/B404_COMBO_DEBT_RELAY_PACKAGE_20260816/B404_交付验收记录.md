# B404 交付验收记录（2026-08-17高级倍投GUI导出证据修订）

## 原B404仍然有效的部分

- 主方案TXT：GBK + CRLF。
- 主方案 `SchemeCreator=` 默认空值。
- 主方案辅助倍投计划：全部为正整数，无小数点。
- 高级倍投倍数：全部为正整数，无0、无小数、无负数。
- 固定取码开出号码段不得整包机械使用0-0。
- 高级倍投状态图仍需包含耐久、回补、救援、软复位、冷却等角色差异。
- 资金模型仍是组合债务接力，不包装成单次命中必然回利。
- PPT仍采用玩家教学型，不讲后台生成过程。

## 2026-08-17高级倍投格式修订

用户在挂机软件GUI中手工修改 `高级倍投_A_耐久软复位` 后，再由软件原生导出TXT，形成更新的高优先级证据。

因此原验收记录中的以下结论废止：

1. 高级倍投配置固定为 UTF-8 BOM + CRLF；
2. 所有TXT的 `SchemeCreator` 都必须空值；
3. 高级倍投只有旧9字段；
4. `中后监控=True / 挂后监控=True` 不可使用；
5. `中后跳转=True-方案名 / 挂后跳转=True-方案名` 不可使用；
6. 高级倍投不能真正跳转到主方案中的其他方案。

## 当前用户实测高级倍投导出事实

- 当前软件原生导出的该高级倍投文件实测为 **GBK、无BOM、CRLF**；
- 每局固定 **16字段**；
- `中后监控`、`挂后监控` 均可为 `True/False`；
- `True` 对应GUI勾选“重新监控”；
- `中后跳转`、`挂后跳转` 可为 `True-主方案名` 或 `False-主方案名`；
- `True` 表示GUI启用跨主方案跳转；
- `中后ID/挂后ID` 负责高级倍投内部局号流转，与主方案跳转是不同层级；
- 高级倍投原生导出的 `SchemeCreator` 可以为软件生成的非空值，因此主方案的空值规则不得机械套用到高级倍投配置。
