- TXT数量：6个主方案 + 6个高级倍投配置。
- 主方案：GBK + CRLF。
- 高级倍投配置：UTF-8 BOM + CRLF。
- SchemeCreator：全部空值。
- 主方案辅助倍投计划：全部为正整数，无小数点。
- 高级倍投倍数：全部为正整数，无0、无小数、无负数。
- 固定取码开出号码段：6-9 / 0-2 / 0-2 / 0-2 / 6-9 / 3-5，不是整包0-0。
- 高级倍投状态图：6套不同配置，包含耐久、回补、救援、软复位、冷却。
- 资金模型：组合债务接力，不包装成单次命中必然回利。
