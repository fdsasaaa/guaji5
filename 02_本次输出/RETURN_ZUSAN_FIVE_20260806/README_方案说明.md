# 中三组选五弹回利套

## 关键结论

本套不是长期盈利承诺，而是把本金5000元约束下的“高返奖、低单期成本、超过50档”做成可执行回利路径。真正的数学底线是：如果要求5个方案同一期全部并投、且任意一个子方案首次有效命中后必须覆盖此前全亏，本套可做到60档；如果改成定位胆低返奖，5000元无法同时满足5方案并投和50档以上逐档回利。

## 玩法与注数

- 玩法：中三组三单式
- 子方案：5个，分别投注 112、224、336、558、779
- 单注金额：2元
- 每期1倍总注数：5注
- 每期1倍总成本：10元
- 单个有效命中返奖：按346元/倍核算
- 返点：按7%流水核算
- 最低投注单位：1倍
- 本金：5000元
- 平台限额：仓库未读取到实时平台接口，执行前必须人工核对单期最高4倍、累计流水1080元是否低于平台限制。

## 高级倍投计划

1,1,1,1,1,1,1,2,1,1,1,1,2,1,1,1,1,1,1,1,2,1,1,1,1,1,1,1,2,1,1,1,2,2,2,2,2,3,2,2,2,2,2,2,2,2,3,2,2,3,3,4,3,3,3,4,3,4,3,3

这个序列不是1、2、4硬追。它分为三段：前段低压，穿插脉冲；中段用2倍承压；尾段只用3/4倍收口，不进入失控加速。

## 资金证明摘要

- 最大档位：60期
- 总倍率：108
- 全链总流水：1080元
- 全链不中净损：1004.40元（已扣7%返点）
- 最大资金暴露：1080元流水 / 1004.40元净损
- 单档首次有效命中最低净收益：第32档约11.20元，第60档约33.60元
- 理论单期有效命中率：5 × 3/1000 = 1.50%
- 60期至少一次有效命中概率：约59.62%

## 导入与运行

1. 导入“方案套装”目录内5个TXT。
2. 导入或手工录入 `GJBTScheme/高级倍投主配置.txt` 的60档计划。
3. 允许5个子方案同时勾选并投；本套回利证明就是按5个方案同一期并投计算。
4. 第60档仍未有效命中，停止，不允许自动进入第61档。
5. 首次有效命中后停止本链，从第1档重新开新链。

## 风险边界

这套的硬伤不是资金暴露，而是命中率不高。60期至少一次命中约59.62%，仍有约40.38%概率全链不中。因此它适合做可控资金实验，不适合包装成稳定盈利系统。
