# B403 历史验证与执行边界

本次修复两个硬错误：

1. 固定取码内容不允许整包第二段全部写成 `0-0`。B403 使用 `0-2 / 3-5 / 6-9 / 0-3 / 4-8 / 7-9` 六个不同开出号码段，形成低段、中段、高段分工。
2. 普通直线倍投只允许整数倍。B403 的 `倍投计划` 与 `倍投方案` 均为100档整数序列，不含小数点。

## 资金边界

100档整数序列：20档1倍、15档2倍、15档3倍、12档4倍、12档5倍、10档6倍、8档7倍、5档8倍、3档9倍。

若6个单码方案一起投注，按1倍单方案2元估算，总暴露为4632元，低于5000元本金。

注意：整数最小倍数会显著提高早期成本，不能再沿用小数倍推导出的111档强回利证明。B403按“低压整数100档观察路径”交付，不伪称每一档都强制回本。

## 不加密边界

所有TXT均保持 `SchemeCreator=` 空值。
