# 本次输入目录

最简单方式：不修改任何文件，直接把整个工作包ZIP发给AI。AI按自动三件套模式执行。

需要自定义时，可放入或修改：

1. 最新开奖历史，例如`最新开奖历史.txt`；
2. `用户本次要求.md`；
3. `本次参数与约束.json`；
4. `PPT样式与视频讲解偏好.md`；
5. `外部参考方案_仅作参考.md`，用于粘贴论坛或他人方案；
6. 软件截图、导出方案、验证记录或指定PPT模板。

不要删除系统根目录的历史索引。新开奖数据不能覆盖旧批次摘要，应使用新文件名和数据哈希。

聊天中也可以直接以“仅作参考”开头粘贴外部方案。系统会采纳、部分吸收或否定，不会照单全收。
