## 2026-08-06导入失败与根因

用户导入首版ZIP时，软件在`Scheme.get_Value()`触发`System.NullReferenceException`。

首版存在四项结构错误：

1. 主方案第2行错误写成玩法类型`定位胆`，而不是一级策略名；
2. 主方案缺少投注监控、真实/模拟投注、盈亏跳转、停止和时间范围等通用字段；
3. `倍投方案`错误写成倍率序列，没有引用配置名；
4. `GJBTScheme/高级倍投主配置.txt`使用了说明型自定义字段，没有采用逐局固定九字段格式。

## 修复结果

修正版主方案：

```text
A001_回利二码_个位-定码轮换.txt
```

高级倍投引用：

```text
倍投类型=1
倍投方案=高级倍投主配置
GJBTScheme/高级倍投主配置.txt
```

高级倍投每局固定字段：

```text
软件名称;ID;倍数;中后ID;挂后ID;中后监控;中后跳转;挂后监控;挂后跳转
```

跳转采用已验证D模式：不中进入下一局，命中回第1局，最后一局不中回第1局；但正式执行要求第29局不中后立即停止，不允许自动进入下一轮。
