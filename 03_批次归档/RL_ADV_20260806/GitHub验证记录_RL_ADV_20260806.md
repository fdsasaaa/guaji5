# GitHub验证记录：RL_ADV_20260806

## 现场故障

用户导入首版ZIP时，软件在 `Scheme.get_Value()` 抛出 `System.NullReferenceException`。JIT调试不是修复方法；根因是方案文件结构不符合软件对象模型。

## 首版根因

1. 第2行把玩法类型 `定位胆` 错当成一级策略；
2. 使用未验证字段 `投注内容=3 7`；
3. 缺少完整通用字段；
4. `倍投方案`错误写成倍率序列，没有引用配置名；
5. `GJBTScheme`文件使用说明型自定义字段，没有采用逐局固定九字段。

首版 `回利二码高级倍投方案套.zip` 已作废。
